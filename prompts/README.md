# Prompt Library

Reusable prompt templates for recurring SRE/DevOps tasks. Each `.md` file documents:
- **Use case** — when to reach for this prompt
- **Inputs** — what to paste in after the prompt
- **Output format** — what to expect back

Files:
- `incident-triage.md` — first-pass triage of an active incident
- `terraform-review.md` — review a `terraform plan` output for risk
- `k8s-manifest-review.md` — review Kubernetes manifests for common misconfigurations
- `security-review.md` — security-focused review of a code diff
